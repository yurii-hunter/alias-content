# alias-content

Картки для гри [Alias для дітей](https://github.com/yurii-hunter/alias): таблиця слів і картинки. На кожен push у `main` GitHub Actions перевіряє їх, збирає статичні файли й публікує на GitHub Pages:

```
https://yurii-hunter.github.io/alias-content/manifest.json
```

## Що де

```
cards.csv              одна картка — один рядок, одна мова — одна колонка
categories.csv         категорії: id, обкладинка, назва кожною мовою інтерфейсу
words.csv              робочий список слів, для яких ще немає картинок (збірка його не читає)
images/<id>.png        ілюстрація картки, квадратна, від 512 px (краще 1024)
privacy/index.html     політика конфіденційності додатку
support/index.html     сторінка підтримки додатку
scripts/build.ts       збірка в dist/
```

`cards.csv`:

```
id,tier,preview,category,uk,en,de,pl,es,fr
dog,free,,pets,Собака,Dog,Hund,Pies,Perro,Chien
tiger,full,yes,wild,Тигр,Tiger,Tiger,Tygrys,Tigre,Tigre
```

- `id` — малі латинські літери, цифри, `-`, `_`. Той самий id у назві картинки: `images/tiger.png`.
- `tier` — `free` (безкоштовна) або `full` (повна версія).
- `preview` — `yes`, якщо повну картку показують у прев'ю покупки (картинку вшивають у додаток). Для безкоштовних порожньо.
- `category` — id категорії з `categories.csv`. У кожної картки рівно одна.
- Далі — колонки мов за кодом. Зараз опубліковані `uk`, `en`, `de`, `pl`, `es`, `fr` (`en` — американська англійська, `es` — іспанська Іспанії).

`categories.csv`:

```
id,cover,uk,en,de,pl,es,fr
pets,dog,Свійські тварини,Pets & farm animals,Haus- und Hoftiere,Zwierzęta domowe,Animales domésticos,Animaux domestiques
```

- `id` — малі латинські літери, цифри й `_`. **Ніколи не змінюється:** додаток зберігає обрані id у налаштуваннях користувачів. Назву можна правити, id ні. Щоб перейменувати категорію, міняйте назви.
- `cover` — id картки з цієї категорії, чия картинка стоїть у списку категорій. Лише `free` або `preview=yes`: ці картинки є на кожному пристрої, зокрема в безкоштовній версії.
- Назви — мовами інтерфейсу додатку. `en` обов'язкова, на неї додаток відступає, коли перекладу немає.
- Порядок рядків — порядок категорій на екрані.

## Як додати

- **Картку:** рядок у `cards.csv` (з категорією) і `images/<id>.png`.
- **Категорію:** рядок у `categories.csv` і картки з її id. З'явиться в додатку з категоріями без його оновлення; якщо дорослий обрав «усі», вона одразу в грі.
- **Мову:** нова колонка. Поки хоча б одна клітинка порожня, мова не публікується і в додатку її не видно. Щойно перекладені всі картки, мова з'явиться в додатку без його оновлення.

## Робочий список слів

`words.csv` — усі заплановані картки, для яких ще немає картинки. Збірка його не читає, тож тут можна тримати незавершене. Коли для слова готова `images/<id>.png`, його рядок переноситься в `cards.csv` (колонки `id`, `tier`, `preview`, `category` і мови; решта лишаються тут).

```
id,tier,preview,level,category,uk,en,de,pl,es,fr,draw
```

- `tier`, `preview` — як у `cards.csv`. Рівно 30 `free`.
- `level` — `1`: слово знає дитина 4 років; `2`: складніше, для 5–7 років або з допомогою дорослого.
- `category` — id категорії з `categories.csv`, та сама, що в `cards.csv`. За нею ж групуються партії генерації картинок.
- Мови: `en` — американська англійська, `es` — іспанська Іспанії.
- `draw` — опис англійською, що саме малювати: одна річ, без фону, у стилі карток з дизайну.

Правила відбору: конкретний предмет, який однозначно малюється однією картинкою; одне слово або усталена назва в кожній мові; без повторів і синонімів у межах мови; без брендів, зброї та страшного. Переклади перед публікацією варто показати носію кожної мови.

## Перевірки

Збірка падає, якщо:

- id повторюється або некоректний; немає картинки чи є картинка без рядка;
- безкоштовних карток не рівно 30; порожнє слово в мові, яка вже опублікована;
- у картки порожня або невідома категорія; категорія без карток; обкладинка не з цієї категорії або не `free`/`preview`; немає англійської назви категорії;
- зібраний контент не прийме додаток 1.0.0 (див. нижче).

## Сумісність зі старими версіями додатку

Додаток уже в магазинах, і люди оновлюються не одразу. Той самий `manifest.json` і файл карток читають усі версії, тож кожна зміна формату має лишати їх робочими.

1. **Лише додавати.** Нові поля в картці, маніфесті чи файлі карток — можна. Прибирати, перейменовувати чи міняти тип наявних — ні.
2. **Не додавати значень у наявні переліки.** Наприклад, `tier: premium`: старий додаток відкине таку картку, а одна погана картка відкидає весь файл. Нова можливість — нове поле.
3. **`schemaVersion` не підвищувати** без окремого рішення: старі версії тоді назавжди лишаються на тому контенті, що вже скачали. `minAppVersion` теж не піднімати, щоб «увімкнути» функцію.

`scripts/lib/compat-v1.ts` — заморожена копія парсера з версії 1.0.0. Збірка проганяє через неї готовий контент і не публікує те, що 1.0.0 відкинула б. Цей файл не змінюють разом із додатком: він описує найстарішу версію, яка ще є в людей.

## Що публікується

- `manifest.json` — версія схеми, мінімальна версія додатку, версія контенту, мови, назва файлу карток. Додаток перевіряє його при кожному старті.
- `cards.<hash>.json` — картки зі словами опублікованих мов.
- `img/<id>.<hash>.webp` — картинки 512 px. Хеш вмісту в назві: файл ніколи не змінюється, тож додаток качає лише нові.

- `privacy/` — політика конфіденційності додатку.
- `support/` — сторінка підтримки: контакт і часті питання.

Жодних даних про користувачів: додаток робить лише анонімні `GET` цих файлів.

## Політика конфіденційності

```
https://yurii-hunter.github.io/alias-content/privacy/
```

Це посилання вказане в App Store Connect і Google Play Console, тож адреса не має змінюватися. Сторінка — статичний HTML українською й англійською, без скриптів і сторонніх ресурсів. Якщо в додатку змінюється щось про дані (мережа, покупки, що зберігається на пристрої), оновіть текст і дату.

## Підтримка

```
https://yurii-hunter.github.io/alias-content/support/
```

Support URL для App Store Connect і Google Play, адреса теж не має змінюватися. Контакт, як грати, часті питання (відновлення покупки, повернення коштів, мови). Якщо в додатку змінюються назви кнопок у налаштуваннях чи поведінка покупки, оновіть сторінку.
